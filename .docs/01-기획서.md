# 마음이음 서비스 기획서

갱신일: 2026-10-26. 초기 범위와 일정은 [초기 기획 기록](archive/01-initial.md)에 보존했다.

## 해결하려는 문제

지원사업 신청자는 공고 조건과 제출 서류를 따로 확인하고 이미 작성한 문서의 정보를 신청 화면에 다시 입력해야 한다. 담당자는 신청 정보·증빙·보완 내역을 오가며 같은 항목을 대조한다. 마음이음은 공고 탐색부터 문서 검토·제출·보완·결과까지 한 흐름으로 연결하는 가상 지원사업 관리 서비스다.

## 사용자와 목표

- 신청자: 공고를 확인하고 직접 입력하거나 작성한 PDF를 올린 뒤 추출 내용을 대조·수정해 제출한다.
- 담당자: 배정된 신청과 원본을 확인하고 보완·결과 사유를 기록한다.
- 관리자: 공고·담당자 배정·업무 통계를 관리한다.

포트폴리오 방문자는 공개 테스트 계정을 사용한다. 별도 공개 시나리오 선택 페이지나 가짜 로그인으로 업무를 대신하지 않는다. 실제 개인정보·민감정보는 입력하지 않으며 실제 지원금은 지급하지 않는다.

## 현재 제공 범위

가상 공고 6종, 공고별 작성 자료 7개, 직접 신청서 작성, PDF 한 묶음 업로드·사용자 검토 요청, 페이지·서류 분할·사진·항목 검토, 신청서 반영·제출·보완·결과를 제공한다. 공개 회원가입은 실제 계정을 생성하지 않는다. `/demo`는 삭제됐다.

OCR 검토 데모는 실제 만들어 저장한 결과로 흐름을 제공한다. OCR 실제 검토는 PDFBox·PaddleOCR와 활성화한 Gemma 4/OpenRouter로 새 처리를 수행한다. 두 방식은 동일 결과 화면을 사용하되 새 공급자 호출 여부를 분명히 안내한다. 자동 선정·진위 판정·실명 인증·지급·결제·공공기관 연계는 범위에 없다.

## 구현 선택

Java/eGovFrame·Spring MVC·JSP/KRDS와 MyBatis/MariaDB로 업무 상태·SQL·트랜잭션을 구현한다. 별도 PDFBox Java 모듈과 Python OCR 서비스를 내부 HTTP로 연결한다. LLM 후보는 원문 근거를 검증하고 사용자 수정·확인 단계를 유지한다.

Oracle 무료 서버의 자원 제약 때문에 데모와 실제 처리를 나눴다. 같은 파일은 내용 주소로 공유하고 공개 계정 자료는 KST 04:00 기준으로 정리한다. 외부 공급자 실패를 성공이나 정답으로 대체하지 않는다.

## 검증과 유지 범위

로컬 업무·권한·상태 회귀, 실제 PDF/OCR/AI 처리, 공개 업로드 대기·검토 결과를 각각 검증했다. 전체 TC 수용 판정·일반 문서 정확도·독립 엔진 비교·장시간 부하·다중 서버·전체 백업 복원은 별도 범위다. Oracle Cloud 배포가 Oracle Database SQL 호환성 증거는 아니다.

기술 수와 화면 수보다 원본 근거·사용자 확인·권한·상태 전이·재현 가능한 실행 증거를 남긴다. 최신 결과는 [15번](15-구현검증결과.md), 배포는 [31번](31-오라클무료서버배포.md), PDFBox 회귀는 [33번](33-PDFBox전환및회귀검증.md)을 따른다.
