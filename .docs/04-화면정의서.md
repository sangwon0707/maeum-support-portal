# 현재 화면 정의

갱신일: 2026-10-26 · 초기 SC 화면 설계와 전체 목록은 [archive/04-initial.md](archive/04-initial.md)에 보존했다. 아래는 실제 제공 흐름 요약이며 정확한 라우트는 현재 Controller가 기준이다.

| 흐름 | 화면/기능 | 현재 동작 |
|---|---|---|
| 진입 | 홈 | 공용 applicant 계정 안내·확인 모달 후 진입 |
| 신청 | 신청 폼 | 신청자가 필드를 직접 입력하고 저장 |
| 첨부 | 문서 첨부 | PNG/JPEG 기존 첨부 또는 작성 완료 PDF 묶음 업로드 |
| 문서 검토 | 업로드 상태·검토 요청 | PDF 업로드 직후 `UPLOADED`; 사용자 요청 뒤 PDFBox/PaddleOCR와 선택 OpenRouter 분석 |
| 결과 확인 | 문서 검토 결과 | 추출값·신청값 대조, 사용자 수정 후 신청에 반영 |
| 업무 | 제출·배정·검토·보완 | 제출 후 관리자 배정, 담당자 검토·보완·결과 조회 |
| 정책 | `/terms`, `/privacy` | 로그인 없이 열람 가능 |

`/demo`와 SC-00 공개 체험은 제공하지 않는다. `PREPARED` 사례는 저장된 결과의 재생이므로 실시간 OCR 화면으로 표시하지 않는다.
