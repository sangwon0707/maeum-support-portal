# 설계 문서·와이어프레임 점검 결과

2026-10-23 · 초기 설계·와이어프레임 점검 기록 / 제품 검증은 15번 문서 별도

## 확인한 범위

- 문서 내부 상대 링크: 끊어진 링크 없음.
- 요구사항: 기능 16개, 비기능 10개, 업무 규칙 12개. 모든 기능 요구사항에 수용 테스트·화면·데이터 연결.
- 화면정의: SC-00~SC-14 총 15개. HTML의 화면 ID와 일치.
- DB: MariaDB 기준 물리 타입을 가진 테이블 22개. ERD와 키·제약·인덱스 후보 문서화. 당시 DB 실행 전 점검이며, 이후 DDL·로컬 DB 검증은 15번 문서 참조.
- HTML: 중복 ID 없음, 외부 리소스 의존 없음. 제공 예시는 변경 없이 .ref에 보존.

## 브라우저 점검

로컬 HTTP 서버와 Playwright CLI 사용. 1440/900/390px × 15개 화면 = 45회 화면 전환에서 표시 화면 1개·요청한 화면 ID 일치·페이지 가로 넘침 없음. 대표 데스크톱 검토 화면과 모바일 신청 화면은 스크린샷을 직접 열어 육안 확인했다. 모든 화면 스크린샷을 저장했으나 모든 스크린샷의 개별 육안 검토를 뜻하지 않는다.

정상/불일치/누락/보완/OCR 실패 시나리오 선택, OCR 처리 중·실패 안내와 추출 표 숨김, 임시저장 안내, 신청→첨부→OCR→최종 확인→진행 화면 이동을 확인했다. 브라우저 콘솔 오류 0건(로그인 예시의 form 외부 비밀번호 입력에 대한 브라우저 안내 1건).

증거: ../output/playwright/1440-SC-11.png, ../output/playwright/390-SC-04.png 및 같은 폴더의 화면별 이미지. 45회 결과는 checks=45, failures=[]였다. 이후 OCR 예시 표시 수정은 시나리오 5종·화면 이동으로 재확인했다.

## 미검증·다음 단계

이는 정적 설계 검토다. 실제 인증·저장·권한·DB·SQL 성능·문자 인식·배포·제품 접근성 수용 테스트는 미실행이다. ERD는 Mermaid 소스로 작성했으며 별도 다이어그램 렌더러로 렌더링 검증하지 않았다. 이후 제작한 예시 서류는 17번 문서, 서비스 구현·검증은 15번 문서를 따른다. 이 절의 미실행 표기는 초기 정적 설계 점검 당시의 범위다.
