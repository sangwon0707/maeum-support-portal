# 문서 OCR 엔진 — 선정 및 검증 계획

갱신일: 2026-10-26 · 상태: OCR/PDF 연동 완료, 후보 성능 비교 미측정

> 초기 선정 근거와 비교 후보 계획은 [archive/16-initial.md](archive/16-initial.md)에 보존했다. 현재 채택 버전과 검증 한계는 아래 요약을 기준으로 한다.

## 현재 구현

- PaddleOCR 3.3.3, PaddlePaddle/core 3.3.0, PP-OCRv5를 사용한다.
- PDFBox 3.0.8로 PDF 페이지와 사진을 처리한다. 신청 PDF는 `UPLOADED` 이후 사용자가 검토를 요청해야 분석한다.
- OpenRouter를 통한 Gemma 4 보조 경로가 연동됐다. 결과는 사용자 확인·수정 후 반영한다.
- 공개 Oracle 앱 증거: 텍스트 PDF 6쪽 `READY` 103.29초, 실제 스캔 1쪽 57줄 111.49초. `PREPARED` 사례는 저장된 결과 표시로 59.11초이며 실시간 추론으로 세지 않는다.

## 비교 계획과 미검증 범위

EasyOCR, Tesseract는 비교 후보로 유지한다. 후보별 같은 자료의 정확도, 속도, 메모리 순위는 아직 측정하지 않았다. 샘플 수가 적고 공개 앱 실측값은 성능 벤치마크가 아니다. 서류 진위 확인, 등록 정보 조회, 자동 자격 판정도 하지 않는다. 데이터 외부 처리 조건은 이용 정책 문서에서 미확정 사실로 다룬다.
