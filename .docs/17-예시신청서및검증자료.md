# 예시 신청서 및 검증 자료

갱신일: 2026-10-26 · 초기 제작 기준: 7쪽 예시 신청서

> 초기 7쪽 문서와 정보 일관성 기준은 [archive/17-initial.md](archive/17-initial.md)에 보존했다. 현재 자동 검증 사례 7개는 `src/main/resources/fixtures/`에 있고, `prepared-intakes/assets/`에는 172개 준비 자료(70 PDF, 102 PNG)가 있다. 생성 PDF/출력은 재생성 가능한 로컬 산출물이며 Git 포함 여부와 배포 근거로 간주하지 않는다. 7쪽 원형 예시와 현재 7개 사례는 별도 자료다.

각 사례의 원문과 이미지형 문서는 `src/main/resources/fixtures/{code}/application.pdf`, `application-scan.pdf`다. 해당 사업에 맞는 내용·사진·사업비·견적을 사용하며 실제 기관 서식·증명서가 아니다. `prepared-intakes/{code}.json`은 sourceSha256과 인식·AI 결과를 보존한다. 현재와 이전 manifest가 가리키는 파생 파일 전체의 출처를 확인했으며 이전 산출물은 현재 동작에 필수라는 뜻은 아니다.

## 제작과 사용

기초 7쪽 문서는 `scripts/build-application-v2.py`, `build-image-only-pdf.py`, `build-comparison-documents.py`로 제작했다. 사업별 서식은 `build-distinct-program-samples.py`, 스캔 PDF는 `build-generated-scan-pdfs.py`, 서비스 fixture는 `prepare-intake-samples.py`로 준비한다. 실제 OCR 결과와 AI 결과 재생성은 각각 `prepare-intake-results.py`, `prepare-intake-ai-results.py`다. 뒤 두 명령은 실제 엔진·외부 공급자 비용·호출 한도를 고려해야 하며 단순 문서 조회 명령이 아니다.

입력 자료·자체 생성 사진·정답 JSON·라이선스는 보존한다. `output/` 제작·렌더링 산출물은 Git에서 제외하며 새 체크아웃에 모두 있다는 전제로 설명하지 않는다. 공개용 스캔 제작 기록은 `references/document-scans/`, 로컬 재생성기가 사용하는 원본 기록은 Git 제외 `.ref/document-scans/`에 있다. 출력 정답 JSON을 실제 OCR·AI 답변으로 주입하지 않는다.

현재 서비스는 PDF 업로드·페이지 렌더링·분할·사진 추출을 지원하고 주소·업태·종목·자부담을 저장한다. 품목별 견적 전체를 독립 업무 테이블로 확정한 것은 아니며 원문 대조를 유지한다. 제작·편집 이미지의 글자 보존과 실제 모델 정확도를 같은 것으로 표시하지 않는다. 상세는 24·25·29·33번 문서를 따른다.
