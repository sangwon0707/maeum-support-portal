# 이용 정책 페이지와 배포 정보

갱신일: 2026-10-26. 실제 `/terms`·`/privacy` 구현과 데이터 흐름을 설명한다. 최초 초안은 [이전 기록](archive/21-initial.md)에 보존한다. 이 문서는 법률 검토 완료를 선언하지 않는다.

## 현재 페이지와 공개 계정

두 정책 페이지는 비로그인 상태에서 조회할 수 있다. 시행일은 2026-10-26이다. 공개 계정 로그인 모달에서 같은 계정의 신청·원본·결과를 다른 방문자가 볼 수 있음과 실제 개인정보·민감정보 입력 금지를 확인한다. 공개 회원가입은 실제 계정을 생성하지 않는다. 로그인 후 홈으로 이동하며 `/demo`는 404다.

## 처리·저장·삭제

원본 PDF 업로드는 서버 저장을 수행하고 다음 화면에서 원본을 확인한다. 사용자 문서 검토 요청 뒤 PDFBox·PaddleOCR가 분할·인식·사진 추출을 수행한다. 신청 정보·제출본·원본·파생 결과는 서버 DB·비공개 파일 볼륨에 저장한다. 브라우저 종료·로그아웃이 서버 삭제를 의미하지 않는다.

공개 계정 자료는 매일 KST 04:00 기준으로 정리하고 5분 주기로 누락분을 처리한다. 진행 중 작업과 다른 신청이 참조하는 공유 파일은 보호한다. 미참조 파일은 보호 기간 후 수거한다. 정기 초기화가 백업·외부 공급자 기록까지 즉시 삭제한다는 뜻은 아니다. 상세는 [30번](30-자료초기화및저장공간관리.md)을 따른다.

## 외부 AI

데모에서는 새 외부 AI 호출이 없다. AI가 활성화된 실제 검토에서는 추출 문구를 OpenRouter와 선택 모델 공급자로 전송해 항목·분류·원문 근거를 해석한다. 현재 운영 검증은 Gemma 4/OpenRouter 성공 증거가 있다. 원본 PDF·사진을 전송하는 구현이 아니라 추출 텍스트를 보내지만 문서에 개인정보가 있으면 그 문구도 포함될 수 있다. 자동 마스킹·공급자 무보관을 보장하지 않는다.

실제 검토 전에 처리 시간·외부 전송·가상 문서 사용 안내를 확인한다. 공급자·모델 계약, 처리 국가·보관·학습 조건은 실제 선택과 정책을 따르며 코드 라이선스로 대신하지 않는다. [32번 연동 문서](32-LLM문서해석연동.md)와 실제 개인정보 처리방침을 함께 확인한다.

## 운영자·호스팅

운영자와 공개 문의처는 `LEGAL_OPERATOR_NAME`, `LEGAL_CONTACT_EMAIL` 환경변수로 주입하며 개인 이메일을 소스에 넣지 않는다. 호스팅은 Oracle Cloud의 대한민국 춘천 리전, HTTPS·프록시는 Caddy·Cloudflare 구성을 사용한다. Tomcat 접근 로그는 7일 보관 설정이고 컨테이너 로그는 순환 제한을 둔다. 확인한 배포 구성은 [31번](31-오라클무료서버배포.md)을 따른다.

이 값들을 아직 정하지 않은 초기 초안과 현재 운영 사실을 혼동하지 않는다. 전체 백업 복원·공급자 보관 조건·법적 권리 행사 절차의 완전성은 각각 별도 확인 범위이며 정책 페이지가 있다는 이유로 모두 충족됐다고 표시하지 않는다.

## 이번 최종 정비 범위

문서의 PDF 미지원·외부 AI 미호출·정기 삭제 미구현·호스팅 미정이라는 낡은 설명을 제거했다. 문서 점검 이후 라이선스 고지·CSS·미사용 공식 상징 정리를 서버 정적 파일에 반영했다. 정책·업무 처리의 전체 재배포나 DB 변경은 하지 않았다.
