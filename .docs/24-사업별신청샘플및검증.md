## 파일과 재생성

- 원본 정답·사진: `fixtures/program-samples/{digital,energy,access,online,safety}/`
- 사진 제작 프롬프트·합성 고지: `fixtures/program-samples/사진제작기록.json`
- 생성기: `scripts/build-program-samples.py`
- PDF 10개: `output/pdf/사업별신청예시/` — 사업마다 텍스트 원본과 이미지 합성 스캔본 각 1개
- 페이지 PNG 30장: `output/images/사업별신청예시/`
- 서비스 다운로드용: `src/main/resources/fixtures/{사례}/business-cert.png`, `estimate.png`, `application.json`
- 로컬 검토 갤러리: `http://127.0.0.1:8098/samples.html` (별도 정적 서버 실행 중에만 접근)

글꼴·제작 도구 준비는 17번 문서를 따른다. 프로젝트 루트에서 실행한다.

```bash
.tools/documents-venv/bin/python scripts/build-program-samples.py
```

각 PDF는 신청서 → 사업계획 → 사업비·일정 → 사진·현황 → 사업자등록증(가상) → 견적서의 6쪽이다. 빨간 경고는 페이지 상단·하단에만 배치한다. 스캔본은 모든 페이지를 이미지화한 PDF로 텍스트 레이어가 없다. 다운로드·업로드용 PNG는 5·6쪽에서 생성한다. ZIP은 만들지 않는다. 생성 결과는 Git에서 제외하며 원본 데이터·사진·생성기는 유지한다.

## 서비스 연결과 경계

`SampleDatasetPolicy`는 고정 사례 코드와 `program.seed_key`를 대응시킨다. 공고 상세·신청서·첨부 화면에는 해당 공고의 예시만 표시한다. 공통 안내 화면에는 전체 사례를 제공한다. 관리자가 새로 만든 공고에는 임의로 기존 사례를 연결하지 않는다.

예시 입력은 신청자가 명시적으로 선택할 때만 수행한다. Service가 소유권·공고 대응·상태·버전을 확인한 뒤 일반 저장 경로로 입력한다. 서류 첨부와 OCR은 자동 실행하지 않는다. 신청자는 PNG를 내려받아 파일 선택·업로드로 첨부한다. 다른 사례 파일을 직접 올리는 행위까지 차단하는 것은 아니며 서류 대조·담당자 검토가 필요하다.
