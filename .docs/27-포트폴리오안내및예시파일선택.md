# 포트폴리오 안내와 파일 선택 모달

갱신일: 2026-10-26. 초기 첨부 모달·진행 연출 검증은 [이전 기록](archive/27-previous.md)에 보존한다.

## 현재 동작

공고에서 작성 문서 업로드를 누르면 운영체제 파일 탐색기 형태의 웹 모달을 연다. 실제 OS 창을 흉내 낸 별도 프로그램이 아니라 서비스의 HTML 모달이다. 사업별 가상 스캔 PDF와 미리보기를 제공하고 직접 파일 선택도 지원한다. 선택 파일 바이트를 실제 multipart 요청으로 서버에 저장한다.

공개 작성 문서 흐름은 PDF 한 묶음 선택이며 서버가 페이지·서류 경계를 나눈다. 기존 직접 작성의 사업자등록증·견적서 이미지 첨부와 구분한다. 모달을 열거나 취소하는 것만으로 신청·검토를 시작하지 않는다.

업로드 완료 후 원본 확인 화면에서 UPLOADED 상태를 유지한다. 사용자가 검토 방식을 선택하고 ‘문서 검토 요청’을 눌러야 처리한다. 로딩 표시와 퍼센트는 요청 후 나타나며, 검토 전에는 자동 인식하지 않는다.

## 안내·접근성

포트폴리오 고지는 최상단에 고정한다. 안내 켜기·끄기와 프로젝트 소개도 이 영역에 둔다. 다음 조작 대상으로 향하는 화살표와 강조 테두리는 실제 콘텐츠·버튼을 가리지 않게 배치한다. 별도 설명 말풍선을 여러 곳에 띄우지 않는다. 안내 상태와 서버 인증·업무 권한은 독립적이다.

모달의 닫기·취소·ESC·포커스 복원, 파일 선택·미리보기·오류 처리는 현재 스크립트와 서버 검증을 따른다. 파일을 첨부한 것처럼 보이기만 하는 고정 화면으로 대체하지 않는다.

## 검토 방식

OCR 검토 데모는 실제 생성해 저장한 결과를 불러오며 새 OCR·LLM을 실행하지 않는다. OCR 실제 검토는 새 서버 처리를 수행하고 처리 시간·외부 AI 텍스트 전송 안내를 확인한다. 두 방식은 같은 결과 검토 화면을 사용한다. 진행률은 승인·선정 결과를 뜻하지 않는다.
