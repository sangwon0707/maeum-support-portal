## 수정한 문제

1. 로컬 Docker DB 연결이 끊겨 일반 요청에서 500이 발생했다. 멈춘 Docker 실행 환경과 해당 DB 서비스를 재시작해 복구했다. 볼륨·기존 신청 데이터는 삭제하지 않았다.
2. 제출 필수 파라미터 누락을 일반 예외로 처리하던 500을 422로 수정했다. 지원하지 않는 HTTP 메서드는 405로 안내한다.
3. DB 연결 장애는 503으로 구분하고 연결 풀 대기 시간을 5초로 제한했다.
4. 개발용 applicant 계정은 제출 이후 새 회차를 만들며 작성·보완 중이면 기존 건을 사용한다. 기존 건은 보존한다. 일반 계정은 기존 1건 제한을 유지한다.
5. 반복 신청의 동시 클릭이 이전 스냅샷을 읽어 두 초안을 만들던 문제를 최신 회차 잠금 조회로 수정했다.

## 원본 UI 확인

참고 프로젝트의 `demo/[caseId]/page.tsx`와 `property/[caseId]/page.tsx` 원본 컴포넌트를 별도 브라우저 실행 환경에서 확인했다. 원본 코드·참고 자료는 수정하지 않았다. 실행 데이터가 폴더에 포함되지 않아 함께 제공된 예시 JSON과 메타데이터 어댑터를 사용했으며 실제 외부 AI 추출을 실행한 것은 아니다. 단계 카드·문서별 진행 막대·완료 수·100% 완료·결과 페이지의 스켈레톤에서 항목으로 전환을 직접 확인했다. 내장 프레임은 이 실행 환경에서 빈 화면이어서 결과 페이지를 별도 탭으로 열어 확인했다. 화면 증거는 `output/reference-pipeline-ui`에 보존했다.
