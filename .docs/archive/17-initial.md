## 현재 파일

아래 경로는 현재 디스크 기준이다. 자료는 PDF와 페이지별 PNG로 제공하며 ZIP은 생성하지 않는다.

가상상점 폴더의 `서류-1.png`~`서류-7.png`는 기본 생성기의 150dpi 검토용 이미지다. 200dpi 비교에는 `image-only/`의 이미지를 사용한다.

## 7쪽 구성과 표현 규칙

1. 신청 서류 확인표: 제출 목록, 가상 사업 기준, 신청 전 확인
2. 신청서: 기업현황·신청내용·사업비를 묶는 다열·병합 표
3. 사업계획서: 업체 소개·지원 필요성·기대 효과·완료 확인 방법
4. 사업비 산출 및 추진 일정
5. 내·외부 현황 사진 2장과 개선 항목별 설명
6. 사업자등록증 예시 (가상)
7. 공급받는 자·공급자·품목·규격·수량·금액을 갖춘 견적서

전북의 큰 프레임·병합 셀과 수원의 제출 확인·상세 설명 구성을 참고했다. 기관명·관인·동의 정책을 복제하지 않았다. 최상단 가상 문서 안내와 최하단 사용 제한 안내 전체만 빨간색(#c00000), 나머지 본문·제목·사진 설명은 검정이다. 사진에는 AI 생성 사실을 별도로 명시한다.

## 두 사례의 정보 일관성

| 항목 | 가상상점 | 가상문구점 |
| --- | --- | --- |
| 대표자 | 가상대표 | 예시대표 |
| 사업자번호 | 0000000000 | 0000000002 |
| 개업일 | 2024-01-01 | 2023-06-15 |
| 신청일 | 2026-10-23 | 2026-11-02 |
| 지원 신청액 / 공급가액 | 3,000,000원 | 2,400,000원 |
| 자부담 / 부가세 | 300,000원 | 240,000원 |
| 총 사업비 | 3,300,000원 | 2,640,000원 |
| 조명 수량 | 10개 | 8개 |
| 가상 추진 기간 | 30일 | 25일 |

가상상점: 간판 1,800,000 + 조명 10×70,000 + 배선 500,000 = 공급가액 3,000,000원.

가상문구점: 간판 1,400,000 + 조명 8×75,000 + 회로 정비 400,000 = 공급가액 2,400,000원.

각 사례 안에서 신청서·계획·견적·증빙은 일치한다. 대체 사례의 주소·연락처·견적일·유효기간·서술 내용·사진도 바꿨다. 사업명·항목명·공통 분류·안내는 유지했다. 기관의 실제 보조율·지원 자격을 재현한 사례가 아니다. 두 사례를 섞어 첨부하면 불일치 시험에 활용할 수 있으나 자동 체험에 아직 연결하지 않았다.

## 재생성

로컬 개발 도구는 ReportLab·pypdf·fontTools·Pillow와 Poppler CLI다. `.tools/documents-venv`가 없다면 다음처럼 준비한다.

```sh
python3 -m venv .tools/documents-venv
.tools/documents-venv/bin/pip install reportlab==5.0.1 pypdf==6.16.2 fonttools==4.60.1 Pillow==12.3.0
```

시스템에 `pdftoppm`이 있어야 한다. Noto Sans KR과 OFL은 `src/main/resources/fonts/`를 사용한다.

```sh
.tools/documents-venv/bin/python scripts/build-application-v2.py
.tools/documents-venv/bin/python scripts/build-image-only-pdf.py
.tools/documents-venv/bin/python scripts/build-comparison-documents.py
```

공통 서식 기능은 `scripts/lib/sample_document_layout.py`에 있다. 가상상점 정답 JSON과 두 사례의 원본 사진은 재생성 입력이므로 유지한다. 이미지 생성 API는 재생성 때 호출하지 않는다. 정답은 평가용이며 OCR 공급자에게 전달하지 않는다.

## 검증 범위와 남은 작업

- 각 사례 7쪽을 렌더링해 글자·표·사진 배치를 확인했다.
- 이미지형 PDF는 페이지당 이미지 1개·추출 텍스트 없음·원본 쪽 크기를 검사했다.
- 두 사례의 합계와 주요 필드 교체, 파일 해시를 확인했다.
- 후속 OCR 연동에서 두 가상 사례의 사업자등록증을 인식한다. 결과는 19번 보고서에 기록하며, 이 자료를 엔진 일반화 정확도의 증거로 삼지 않는다.
- 서비스에 기본·비교 사례의 사업자등록증·견적서 PNG를 연결했다. 샘플/실제 OCR을 구분하며 PDF 업로드·페이지 변환은 미지원이다.
- 현재 서비스 DB에는 주소·품목별 비용·자부담·전체 계획 항목이 모두 저장되는 구조가 없다. 문서 항목 추가가 곧 서비스 폼·DB 확장을 의미하지 않는다.
