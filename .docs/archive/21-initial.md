# 이용 정책 페이지와 배포 정보

> 보존 기록: 본문의 예정·미구현·검토 대기·배포 상태는 작성 당시의 기록이다. 현재 기능과 운영 상태는 원래 번호 문서 및 15·31~33번을 따른다.


> 2026-10-26 갱신: 아래 최초 작성 기록의 문안 0.1은 현재 페이지에 적용하지 않는다. 현재 약관·처리방침은 버전 1.0이며 페이지에는 내부 검토·배포 예정 문구를 표시하지 않는다. 최신 결정은 이 문서 하단을 따른다.

작성일: 2026-10-23. 푸터에서 로그인 없이 이용약관과 개인정보 처리방침을 열 수 있도록 구성했다.

## 페이지와 연결

- `/terms`: 서비스의 범위, 계정·권한, 이용자 자료, 문자 인식·AI 보조, 이용 제한, 변경·중단, 종료·삭제 요청, 책임·분쟁, 운영자 문의.
- `/privacy`: 처리 항목·목적·수집 방법, 보관·파기, 외부 처리, AI·국외 이전, 권리 행사, 쿠키, 보호 조치, 문의와 변경.
- 공통 푸터: 이용약관 / **개인정보 처리방침** / 신청·서류 안내. 개인정보 링크는 굵게 표시한다.
- 회원가입: 두 문서를 확인할 수 있는 링크를 추가한다. 이 변경으로 약관 동의 기록이나 별도의 개인정보 동의를 수집한 것으로 표현하지 않는다.

`LegalController`와 `LegalSettings`가 법률 페이지의 라우팅 및 공개 운영자 정보를 담당한다. 설정값은 `c:out`으로 출력하며, 문의 이메일은 일반적인 이메일 형식일 때만 mailto 링크를 만든다. 유효하지 않은 값이나 누락된 값으로 연락처를 추정하지 않는다.

## 현재 처리 내용과 일치시키기

실제 가입·신청·파일·감사·OCR 코드와 대조하여 작성했다.

- 비밀번호는 해시로 저장한다. 계정과 신청·파일은 저장되므로 개인정보를 전혀 수집하지 않는다고 설명하지 않는다.
- 자동 탈퇴·보관 기한별 일괄 파기·백업 삭제 기능은 없다. 로그아웃·체험 만료·서류 교체가 물리 삭제라는 표현을 사용하지 않는다.
- AI는 네 항목만 보내는 것이 아니라 OCR 영역의 원문과 줄 번호를 보낸다. 문서 이미지·신청값·계정 비밀번호는 AI 입력에 포함하지 않는다. OCR 원문 자체의 개인정보는 자동 마스킹하지 않는다.
- OpenRouter는 실제 추론 제공업체를 거칠 수 있다. 수신 국가·업체·보관 기간·학습 사용·ZDR을 미확인 상태에서 보장하지 않는다.
- 광고·행동 분석 SDK는 현재 앱에 추가하지 않았다. 필수 세션 쿠키를 사용한다. 배포 호스팅·프록시 로그는 아직 확정하지 않았다.
- 실제 정부 접수·사업자 진위 확인·지원금 지급 기능은 없다.

## 확정할 배포 정보

현재 문안은 버전 0.1이며 공개 배포 전 검토 상태를 페이지 상단에 명시한다. 시행일을 이미 배포한 날짜처럼 작성하지 않는다.

| 설정·정책 | 필요한 정보 |
| --- | --- |
| `LEGAL_OPERATOR_NAME` | 실제 운영자 개인명 또는 사업자명 |
| `LEGAL_CONTACT_EMAIL` | 개인정보 권리 행사·이용 문의를 받을 실제 이메일 |
| `LEGAL_HOSTING_PROVIDER` | 호스팅 사업자. 별도로 처리 업무·저장 국가·로그·백업 조건도 확인 |
| 보유·파기 | 계정·신청·첨부·감사 로그별 목적·기간, 삭제 요청·백업 파기 절차 및 실제 실행 수단 |
| 외부 AI | 실제 계약 상대와 추론 업체, 이전 국가·연락처·항목·시점·방법·목적·기간, 적용 근거·고지·필요 절차 |
| 회원가입 안내 | 최종 약관을 적용할 때 필요한 안내·동의 절차와 버전 기록 정책 |
| 적용일 | 위 내용 확정 후 최초 시행일과 변경 안내 방식 |

공개 정보는 `.env.example`의 세 변수를 참고해 실행 환경에 주입한다. Docker 앱에도 전달하도록 Compose를 연결했다. 로컬 `dev.sh`는 환경 파일을 자동으로 읽지 않으므로 실행 전에 해당 변수를 내보내거나 현재 로컬 실행용 `.env.ocr`에서 함께 설정한다. 실제 이메일·이름을 코드에 임의로 채우지 않는다.

페이지 두 개를 추가한 사실을 법률 준수 완료나 운영 배포 준비 완료로 해석하지 않는다. 운영 조건과 정보주체 권리 처리 수단을 확정한 뒤 최종 문안을 검토해야 한다. 다른 서비스의 약관·법정 보존 기간을 그대로 복사하지 않았다.

## 2026-10-26 공개용 정책 문안 갱신

- 참고: [모아무비 이용약관](https://moamovie.sangwonlee.dev/terms), [모아무비 개인정보 처리방침](https://moamovie.sangwonlee.dev/privacy), [Next2U 정책 모달](https://next2u.sangwonlee.dev/). 포트폴리오 범위, 자료 권리, 금지행위, 개인정보 흐름, 문의 구조를 참고하고 서비스별 사실은 복사하지 않았다.
- [개인정보보호위원회 안내서 목록](https://pipc.go.kr/np/cop/bbs/selectBoardList.do?bbsId=BS217&mCode=G010030030)의 2026.4. 작성지침을 참고 자료로 확인했다. 정책 문안 변경을 법률 준수 전체나 호스팅 검증의 완료로 표현하지 않는다.
- 두 페이지는 시행일 2026-10-26, 버전 1.0으로 게시한다. ‘검토 중·배포 전·등록 예정’ 문구는 제거했다.
- 페이지 상단 및 공통 고정 안내에 포트폴리오용 데모와 실제 개인정보 입력·업로드 금지를 빨간색으로 표시한다.
- 같은 공개 계정의 신청·원본·처리 결과를 다른 방문자가 볼 수 있음을 명시한다. 회원가입 화면은 계정 생성 기능과 구분한다.
- PDF 업로드 저장 → 원본 확인 → 명시적인 문서 검토 요청 → 서버 OCR → 사용자 확인·반영 흐름을 기술한다. 원본·분할본·쪽별 미리보기·사진·신청·제출 이력은 서버 저장이다.
- 현재 공개 Java 설정은 OCR_AI_ENABLED=false이다. 통합 PDF 처리도 외부 AI를 호출하지 않는다. 따라서 현재 기능의 외부 전송 없음으로 안내하고, 별도 사업자등록증 OCR의 외부 AI 옵션을 공개 활성화할 때는 수신자·국가·보유 조건 등 실제 공급자 정보를 확인하고 정책·필요 고지 절차를 함께 바꿔야 한다. 공급자 키가 있다는 사실만으로 외부 AI를 사용 중이라고 쓰지 않는다.
- 신청·서류·업무 기록의 보관 기준은 서비스 운영 기간과 해당 목적 존속 기간이다. 로그아웃·신규 신청·교체를 삭제로 표현하지 않는다. 목적 종료·초기화·적법한 삭제 요청 시 운영자가 DB와 관련 파일을 함께 수동 파기한다. 이메일 문의도 답변·후속 처리 목적이 끝나면 정리한다. 정기 자동 삭제나 백업 자동 삭제 기능이 있다는 뜻이 아니다.
- 공개 운영자·이메일은 사용자가 제공한 레퍼런스의 공개 문의처로 설정했다. 실제 값은 Git에서 제외된 실행 환경변수로 주입한다. 외부 페이지 원본은 보존하되 연락처 포함 원본이 커밋되지 않도록 .ref/legal-pages를 제외한다.
- 호스팅 업체·서버 국가·프록시 접근 로그·백업 조건은 현재 로컬 실행만으로 확인할 수 없다. 이후 배포 구성이 이를 추가하면 실제 처리 사실에 맞춰 고지해야 한다. 확인되지 않은 외부 위탁 업체나 로그 보관 기간을 문안에 창작하지 않는다.
