## 선정과 확인 범위

중앙정부 소속기관 2곳과 지방자치단체·지자체 직접 운영 서비스 8곳을 선정했다. 민간 업체 제작사 포트폴리오나 단순 `.do` 확장자는 eGovFrame 적용 증거로 사용하지 않았다. 공식 포털의 대표 적용사례 또는 적용점검 사업 기록으로 선정했다.

**적용 이력과 당시 화면 관찰은 별개 근거다.** 공개 기록으로 현재 서버의 정확한 eGovFrame 버전, 모든 프런트엔드의 기술, 최신 개편 이후 전체 코드까지 보증하지 않는다. KRDS 적용 인증 여부도 별도로 조사하지 않았으므로 단정하지 않는다.

공식 목록은 웹 검색 캐시와 실제 브라우저의 건수·정렬이 달랐다. 직접 확인한 목록의 원문 링크를 아래에 기록하며 캡처 파일은 보관하지 않는다.

## 우리 서비스에 대한 결론

아래는 관찰에서 도출한 설계 제안이며 아직 합의된 디자인 규칙이나 구현 완료 보고가 아니다.

1. **업무 구조는 청주시·대전 동구 통합예약을 우선 참고한다.** 기관 소개형 대형 홍보 화면보다 검색·분류·접수 목록·나의 신청·이용 안내가 우리 서비스에 가깝다.
2. 첫 화면은 주된 과업인 사업 찾기와 신청 현황에 바로 진입할 수 있어야 한다. 홍보 문구와 그림의 면적을 먼저 정하지 않는다.
3. 콘텐츠는 공고의 대상·기간·지원 내용·서류·신청 방법·보완 절차로 채운다. 실제 없는 공고·통계·기관 활동으로 분량을 늘리지 않는다.
4. 디자인 규칙은 별도 단계에서 KRDS 토큰과 서비스 과업을 근거로 정한다. 이번 스크린샷의 색상·둥근 모서리를 그대로 섞어 쓰지 않는다.
5. 공공사이트라도 가로 넘침·과도한 팝업·홍보 위주 첫 화면은 개선 대상으로 본다.

## 파일과 이용 범위

스크린샷은 디자인 조사·비교를 위해 보존한다. 이미지·사진·기관 로고·캐릭터의 권리를 취득한 것이 아니며, 실제 서비스 에셋으로 복사하지 않는다. HTML 갤러리는 로컬 정적 문서이고 원격 게시·커밋은 하지 않았다. 첫 화면의 슬라이드 내용은 캡처 시점에 따라 다르다. 화면 너비는 기본 Chrome 창 기준이며 동일 고정 뷰포트 비교 실험은 아니다.
