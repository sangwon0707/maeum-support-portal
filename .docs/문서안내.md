# 문서 안내

갱신일: 2026-10-26. 현재 구현 설명과 당시 설계·검증 기록을 구분한다. 소스·마이그레이션·실행 증거와 다르면 최신 구현 문서와 후속 변경을 우선 확인한다.

## 현재 상태

| 구분 | 확인된 상태 |
| --- | --- |
| 업무·데이터 | Java/eGovFrame·MyBatis·MariaDB·Flyway V12, 신청·제출·배정·보완·결과 구현 |
| 화면 | KRDS 기반 자체 서비스, 공고 6종·직접 작성·작성 문서 업로드·나의 신청·마이페이지 |
| 공개 경로 | 공개 테스트 계정 로그인과 홈 이동. `/demo`는 삭제되어 404 |
| 문서 | 한 묶음 PDF 업로드 후 명시 요청, 원본·분할 서류·사진·신청 항목 검토·수정·반영 |
| 문서 엔진 | Java PDFBox 3.0.8 + PaddleOCR/PP-OCRv5 + OpenCV + 선택 LLM |
| AI | Gemma 4/OpenRouter 실제 호출·원문 검증·누락 보완·차이 표시. NIM 성공은 확인되지 않음 |
| 데모 | 실제 생성한 결과를 사전 저장해 동일 검토 화면으로 제공. 새 OCR·AI 호출 없음 |
| 원격 운영 | Oracle Docker Compose·Caddy·Cloudflare HTTPS·Fail2ban 적용, 공개 실제 검토 통과 |
| 자료 관리 | 공개 계정 KST 04시 초기화, 파일 내용 주소 공유·미참조 수거 구현 |
| 미검증 범위 | 일반 문서 정확도 지표·장시간 부하·다중 서버·전체 백업 복원·Oracle Database 호환성 |

## 공개 출처와 로컬 자료

공개할 자체 출처·생성 기록은 [references](references/SOURCE_PROVENANCE.md)에 있다. `.ref/`는 로컬 보존 전용이며 Git에서 제외한다. 필요한 공식 소스와 재생성 기록만 남겼다. 실제 기관 서식 원본·정책 참고 페이지·정부 사이트 캡처를 서비스 코드로 배포하지 않는다.

과거 아키텍처는 [v0.1](아키텍처설계서-보완전-v0.1.md)과 [v0.2](archive/architecture-v0.2.md)에 보존한다. `archive/`와 날짜가 붙은 실행 기록은 그 당시 상태를 설명하며 현재 서비스 화면과 혼동하지 않는다.

## 소스·운영 반영의 구분

기능 버전은 Oracle에 배포해 검증했다. 이후 공개 범위 정비와 Git 초기화를 완료하고 같은 이름의 비공개 저장소를 새로 만들었다. 라이선스 고지·CSS와 미사용 공식 상징 제거는 서버 정적 파일에 반영했으며 전체 앱 이미지 재배포·컨테이너 재시작은 하지 않았다. 현재 저장소의 Actions는 비활성화다.
