## 사용 범위

현황 설명용 가상 장면이다. 실제 공사 필요성·자격·안전을 증명하지 않는다. 외부·내부는 같은 가상 업종을 표현하는 별도 생성 이미지이며 실제 공간의 구조적 일치나 전후 시공 결과를 입증하지 않는다. 배선 상태는 사진만으로 판정하지 않는다. 원본 생성 이미지의 출처 메타데이터를 보존한다.
